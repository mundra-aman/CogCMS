# Contributing

Contribute bug fixes, documentation, accessibility improvements, tests or product improvements. Discuss substantial behavior or architecture changes in an issue first. Work on a branch, follow [AGENTS.md](AGENTS.md), and use fictional local data. Submit a PR against the default branch. Do not include credentials, private deployment configuration, customer records or generated build files.

Run the typecheck, test suite and build sequentially. Include exact results and distinguish setup or starting-commit failures from new failures. Explain design choices, limitations and AI/tool assistance in the PR template. AI assistance is allowed; be ready to trace and change the code you submit.

Maintainers review behavior, site isolation, tests and reasoning. Contributions do not require paid services. Candidates completing the optional [assignment](ASSIGNMENT.md) should also follow its timebox and submission instructions.
