# Support

Start with [local setup](README.md#local-setup), [deployment](docs/DEPLOYMENT.md), [website integration](docs/API.md) or the [legacy migration guide](docs/MIGRATION.md).

Search [existing issues](https://github.com/mundra-aman/CogCMS/issues) before opening a new one:

- **Bug:** use the bug-report form with a minimal reproduction, commit/version, expected result and actual result.
- **Feature idea:** use the feature-request form and describe the user problem, current workaround and alternatives.
- **Setup or usage question:** use the question form. Include the command, environment and redacted error, and say which setup step you reached.
- **Security concern:** follow [SECURITY.md](SECURITY.md); do not use a public issue to share vulnerability details.
- **Conduct concern:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Use fictional sample data and remove credentials, cookies, API keys, database connection strings and customer information from logs and screenshots. Avoid uploading full database dumps or environment files.

Support is provided through the repository when maintainers or contributors are available. There is no response-time commitment, managed hosting service or production operations support included. Operators remain responsible for their own deployments and recovery procedures.
